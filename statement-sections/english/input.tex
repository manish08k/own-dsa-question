The first line contains three integers $n$, $k$ and $m$ ($1 \le n \le 10^5$; $0 \le k \le 10^4$; $0 \le m \le 10^9$) --- the number of days, the daily requirement, and the maximum allowed debt.

The second line contains $n$ integers $a_1, a_2, \ldots, a_n$ ($0 \le a_i \le 10^4$) --- the focus points earned on each day.
