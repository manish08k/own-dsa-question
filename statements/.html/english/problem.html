Focus Streak
time limit per test
1 second
memory limit per test
256 megabytes
input
standard input
output
standard output

Manish wants to stay productive, so every day he needs to complete work worth $$$k$$$ focus points. On day $$$i$$$ he earns $$$a_i$$$ focus points.

Manish chooses a non-empty segment of consecutive days $$$[l, r]$$$ and starts it with a balance equal to $$$0$$$. On each day $$$i$$$ of the segment, his balance changes by $$$a_i - k$$$: if $$$a_i \gt k$$$, the surplus is saved, and if $$$a_i \lt k$$$, the shortage is borrowed.

A segment is called sustainable if after each day of it the balance is not less than $$$-m$$$. Formally, a segment $$$[l, r]$$$ is sustainable if for every $$$j$$$ from $$$l$$$ to $$$r$$$, $$$$$$\sum_{i=l}^{j} (a_i - k) \ge -m.$$$$$$

Find the length of the longest sustainable segment, or report that there is none.

Input

The first line contains three integers $$$n$$$, $$$k$$$ and $$$m$$$ ($$$1 \le n \le 10^5$$$; $$$0 \le k \le 10^4$$$; $$$0 \le m \le 10^9$$$) — the number of days, the daily requirement, and the maximum allowed debt.

The second line contains $$$n$$$ integers $$$a_1, a_2, \ldots, a_n$$$ ($$$0 \le a_i \le 10^4$$$) — the focus points earned on each day.

Output

Print a single integer — the length of the longest sustainable segment. If there are no sustainable segments, print $$$0$$$.

Examples

Input
6 4 2
6 1 1 9 2 2
Output
3
Input
7 4 3
2 1 7 0 3 5 1
Output
4
Input
3 5 0
1 2 3
Output
0

Note

In the first example, the segment $$$[4, 6]$$$ (the days with $$$9, 2, 2$$$) is sustainable: the balances after each day are $$$5, 3, 1$$$, and all of them are at least $$$-2$$$. The segment $$$[1, 3]$$$ is not sustainable: the balances are $$$2, -1, -4$$$, and $$$-4 \lt -2$$$. No segment of length $$$4$$$ or more is sustainable.

In the second example, the segment $$$[3, 6]$$$ (the days with $$$7, 0, 3, 5$$$) is sustainable: the balances are $$$3, -1, -2, -1$$$, all at least $$$-3$$$. Adding day $$$7$$$ gives balance $$$-4 \lt -3$$$. No segment of length $$$5$$$ or more is sustainable.

In the third example, already on day $$$1$$$ the balance becomes $$$1 - 5 = -4 \lt 0$$$, and every other day is similar, so there are no sustainable segments.
